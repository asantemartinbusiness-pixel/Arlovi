## Vision and art direction
A multi-brand fictional Manchester-rooted design, commerce and experiences group:
- **Northline Atelier** — interior architecture, lighting, hospitality environments and digital work.
- **Harbor Supply** — furniture and lighting objects, trade accounts and fulfilment.
- **Northline Experiences** — design consultations, workshops and private events.

The visual identity explicitly avoids interchangeable SaaS template art: editorial typography (Georgia/Inter), off-white uncoated-paper surface `#F2EFE8`, near-black `#252923`, oxidised copper `#A25237`, sage `#828B77`, oversized typographic layouts, generous visual tension, deliberately restrained animation and original SVG forms. Signature line: **Spaces worth staying in.**

The bespoke portfolio uses hand-authored vector geometry: pendant study with metallic shading, editorial art direction, collection cards, responsive navigation and a working (browser-local only) project enquiry. Cards can filter by Spaces / Objects / Experiences. The native website record separately demonstrates the platform's editable block, CMS, multi-page navigation and form embedding editors. The bespoke preview is not automatically reverse-synchronised into the native block editor; this is a documented feature-parity limit, not a claim of WYSIWYG equivalence.

## Guardrails and verification
- Do not overwrite existing Northline Atelier or Harbor Supply examples.
- Seed only missing records; preserve local edits and private tenants.
- Every seeded connection has `not_connected`; no fake external send, publish, payment, deploy or AI execution.
- AI profiles have model `not_connected`, no externally enabled actions, recorded token cost zero.
- Demo passwords, sensitive real identities, bank credentials or private customer data are not provided.
- The portfolio enquiry is opt-in and saved to the user's browser (IndexedDB), with an explicit local-only notice and no outbound request.
- Functional testing must include `npm run typecheck`, `npm run test`, `npm run build`, and manual desktop / tablet / mobile inspection.
- Native app quality still depends on each actual editor's schema and interaction implementations; population of a record does not prove complete feature capability.
