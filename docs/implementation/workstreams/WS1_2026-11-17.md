# WS1 — Core experience: Headquarters, assets, attention and access (2026-11-17)

Branch: `ws1-core-experience`. Apps: ASSET, HQ, INBOX, ADMIN. All data is read and written through the existing
workspace repo (`context.mutate`, `useCollection(s)`, `useRecord`) and scoped to the current organisation.
Screens were checked at 1440px and 390px with Playwright screenshots (no horizontal page scroll at either width).

## ARL-ASSET-001 Asset Library — `/o/:org/asset/assets`

**Changes**
- Folder rail (new `assetFolders` collection): All assets, Not in a folder, one entry per folder with counts.
  Create, rename (with description) and delete; deleting moves its assets to "Not in a folder", never deletes them.
  The open folder is in the address (`?folder=`), so it can be linked to and survives a reload.
- Toolbar: search across name, tags, licensor, photographer, original file name, alt text and recorded uses (all
  terms must match); type filter; licence filter (clear / expiring / expired / unrecorded); six sorts; grouping
  (type, licence, folder, first tag; shared with the contract "Group the library" action); grid/list toggle.
  Layout and sort are remembered per device (localStorage, guarded).
- Tag chips (most used first) toggle a tag filter; "Clear filters".
- Grid tiles with real previews, checkbox multi-select and "Select all"; selection bar: Move or tag, Check rights,
  Archive. List view (DataGrid) has the same bulk actions plus folder, stored size and linked count columns.
- Upload: any file type, several at once, up to 8 MB each, by picker or by dropping files anywhere on the library.
  Each file is read with the File API, stored as a data URL in the record body in IndexedDB, with MIME type, original
  name, byte size, image/video dimensions and video/audio duration, and a real SHA-256 checksum (warns when the same
  file is already in the library; Governance → Duplicates picks it up). Folder, tags, licence and rights holder are set
  in the same dialog.
- New overlays: asset editor, link records, folder editor, bulk edit. New overflow actions: Edit details, Link to a
  record, New folder.

**Persistence**: folders, uploads, tags, folder moves and edits survive reload (e2e).
**Tests**: `tests/unit/ws1-asset-library.test.ts` (11), `e2e/ws1-asset-library.spec.ts` (3 incl. 390px).
**Status**: Verified.

## ARL-HQ-001 Executive Home — `/o/:org/hq/home`

**Changes** (four new cards, all in "Arrange cards")
- **Needs attention**: overdue, stopped and assignment items from the inbox attention model (same triage state, so a
  resolved or snoozed item disappears here too) plus asset licences that lapse within 14 days while still in use.
  Filter chips by source; each row has Open (navigates to the real record route) and Acknowledge (writes triage).
- **Objectives**: active objectives ordered by confidence, progress meter, "N of M key results met", Check in.
- **Department health**: per department people/AI, open and overdue work, high risks, off-track objectives;
  status with stated reasons; name opens the department workspace.
- **Decision log**: latest decisions (timeline events of kind `decision`) with decider, reasoning, related record link,
  review-due flag and "Mark reviewed"; "Log a decision" (also in the actions menu).

  previously read as 136% done).

**Persistence**: check-ins and decisions verified after reload. Existing assertions (Waiting on you, Receivable,
Overdue, Dismiss) unchanged.
**Tests**: `tests/unit/ws1-hq-command.test.ts` (9), `e2e/ws1-hq-command.spec.ts` (4 incl. 390px).
