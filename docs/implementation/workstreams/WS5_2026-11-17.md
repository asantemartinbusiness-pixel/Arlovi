# WS5 — Studio editors (2026-11-17)

Branch `ws5-studio`. Scope this pass: LAYOUT (priority), PHOTO, PRESENT, VIDEO.
MOTION, DESIGN, DOCS and SHEETS were inspected and left unchanged; their existing
library specs still pass. `src/applications/visual` and `t6kit` are imported by
WEB, CONNECT and IT as well, so they were treated as shared and not edited.

## ARL-LAYOUT-002 Publication Editor — `/o/:org/layout/publications/:id`

**Status: Verified**

Changes
- Selection handles (8) on the selected frame of any kind; resizing snaps moving
  edges to margins, columns, page centre and other frames. Shift keeps the
  proportions; placed images keep their ratio unless Alt is held.
- Dragging now snaps the left, centre or right edge (and top/middle/bottom) to the
  same lines, with a visible snap guide; ⌘/Ctrl turns snapping off, Shift locks an axis.
- Keyboard: arrows nudge 1pt (Shift 10pt), Delete/Backspace remove, ⌘D duplicates,
  ⌘Z / ⇧⌘Z / ⌘Y undo and redo, Escape clears, V/T/F/R pick tools.
- Arrange panel in the inspector: align left/centre/right/top/middle/bottom to the
  margins or to the trim; span the column grid from a chosen column; bring to
  front/forward/backward/back; duplicate; lock; delete (a deleted frame in a thread
  relinks its neighbours instead of cutting the story).
- Layers list ("Frames on this page") with select and lock toggles.
- The **Layout** tab now shows a Page grid panel (margins, facing pages, column
  count and gutter, show columns, baseline increment) — before it showed the same
  panel as Pages.
- Text frames placed with the tool get their own story (previously they re-poured
  story 1); the inspector edits a frame's copy in place and sets its first-paragraph
  and body styles.
- Stage: the spread is centred with `margin:auto` so wide spreads scroll fully into
  view (the left page was clipped before); it fits the window on open; "Fit" button;
  the three stacked toolbar rows became one compact strip.
- Export the pages on screen as SVG, serialised from the canvas without guides or
  selection (placed images are already data URLs, so the file is self-contained).
  The existing HTML export and print proof are unchanged.

Persistence: every change goes through the shared document handle (undo stack,
local draft, debounced write to the record). E2E reloads and finds the frame and the
3-column grid.
Responsive: 1440 and 390 screenshots checked; on 390 the Pages/Frame panels open
from the header toggles and there is no horizontal page scroll.
Tests: `tests/unit/ws5-layout-arrange.test.ts` (10), `e2e/ws5-layout-editor.spec.ts` (3).
Gaps: single selection only (no multi-select align/distribute); no rotation handle;
SVG export uses font names, not embedded fonts.

## ARL-PHOTO-002 Raster Editor — `/o/:org/photo/photos/:id`

**Status: Verified**

Changes
- Bug: seeded images stored without pixels composited to flat grey although the
  panel says the background is a generated raster. They now get that raster
  (cached per size).
- Bug: the canvas measured its frame only after the document opened, so it drew at
  full size behind the panels. It now fits the window on open.
- Image strip: open a photo from this device (File API) as a new layer above the
  picture layers and below the adjustment stack, resizing a still-generated canvas
  to the photo; rotate 90° left/right and flip horizontal/vertical as layer
  transforms (non-destructive, undoable; blocked with a reason when a mask is
  enabled); "Before" toggle bypasses all adjustments; PNG export via `canvas.toBlob`,
  logged on the record.
- Compact toolbar with icon undo/redo.

Persistence: reload keeps the opened photo layer and the canvas size.
Tests: `tests/unit/ws5-photo-transform.test.ts` (6), `e2e/ws5-photo-editor.spec.ts` (2).
Gaps: rotation is in 90° steps (the crop tool still straightens at any angle); masks
are not transformed.

## Shared-file proposals (not made)

- `src/applications/visual/kit.tsx` `useMeasure` attaches its ResizeObserver once
  with `[]` deps; any caller that renders the measured element conditionally gets
  a size of 0 forever (the PHOTO bug above). Suggest re-observing when the ref
  changes (callback ref).
- `ds-toolbar` inside `.vx-stage-tools` draws a border and full padding per group,
  which stacks editor toolbars into rows. WS5 overrides this per app
  (`lx-tools`, `ph-tools`, `vd-tools`); a shared compact variant would remove that.
- `playwright.config.ts` always starts a server on 5173 even when `BASE_URL` is set;
  agents had to use a private config to stay on their own port.
