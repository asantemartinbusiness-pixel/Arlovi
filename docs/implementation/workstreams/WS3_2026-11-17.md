# WS3 — Business operations: depth pass, 2026-11-17

Branch: `ws3-operations`. Apps in scope: LEGAL, CARE, PROJECT, COMMS (FIN, CRM and HR untouched).
Everything below persists through the existing workspace mutations (`context.mutate.create/patch`, IndexedDB via
Dexie), is scoped to the current organisation, and records an audit event with the actor.

### ARL-LEGAL-003 · Contract Detail — `/o/:org/legal/contracts/:id`
- **Changes (Overview):**
  - *Key dates and renewal* card: start, end (days to go), notice period, notice-by date, renewal alert, recorded
    decision; inline edit of dates, notice days, auto-renew and renewal decision (renew / renegotiate / terminate).
    Signed contracts keep executed start/end read-only. States plainly that a decision does not serve notice.
  - *Obligations* card: list sorted open-first with due state; **add** an obligation inline (title, due, owner,
    detail — created in `obligations` with `contractId`, so it also appears on the Obligation Calendar);
    **complete / reopen** with completedBy/At.
  - *Review cycle* card: rounds stored in `body.reviews`; "Request a review" opens the reviewer picker (which now
    starts a round and targets the open contract — previously it used the list selection and could pick the wrong
    contract on the detail page); decision **Approve / Request changes / Reject** with a required reason for the
    latter two; approve → `approved`, otherwise → `draft`; round history with decider and date. Explicitly not a
    signature or acceptance.
  - *Linked records* card: link a CRM company (suggested from the counterparty name, never auto-linked), a deal
    (filtered to that company) and a project; open deal / open project / companies list.
- **Changes (History):** "Store a new version" (label + text prefilled from the latest version; duplicate labels
  refused); the new version feeds the Redline comparison.
- **Seed:** contracts of type insurance/saas/customer with a notice period are marked `autoRenew`.
- **Persistence:** verified after reload in e2e (obligation completion, review round + status, renewal decision,
  project link, stored version).
- **Responsive:** 390 checked; obligation rows wrap the action below the title; no overflow.
- **Status:** Verified.

- **Changes:** queue counts (mine / unassigned / breaching or at risk, open cases only); "All / SLA risk" view and
