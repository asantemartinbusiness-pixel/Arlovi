# B1 · Documents, Sheets and Presentations · dispositions

**Signatures.** Documents: the page and its review state (save, review and publish are three separate facts). Sheets: the grid, formula integrity and the selected range (inspector follows the selection; overwrites are previewed). Presentations: the slide and the audience (what is hidden or private is named as such).

Evidence: before shots `shots/B1/before`, after shots `shots/B1/after`, one deep-link capture per overlay in `shots/B1/survey/<screen>_<overlay>_<kind>.png` (all 102 opened a dialog, none overflowed horizontally). Paths relative to the scratchpad.

Tally (overlay entries): Refined 94, Rebuilt 5, Enhanced 3.
Every overlay received: a width preset (OVERLAY_WIDTH), the primary-left / dismiss-at-end footer (OverlayActions via formFooter/docFooter), and, on record screens, an OverlaySummary identity head (all drawers, plus decision modals). Rows say what else changed. No overlay is claimed Verified: none was left untouched.
