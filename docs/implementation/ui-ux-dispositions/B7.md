## Signatures

- **Customer Care: the clock against the SLA.** One `SlaClock` band opens every case: the figure remaining (or over), a bar with the at-risk mark at 75%, the policy, the business hours it is counted in, whether waiting on the customer pauses it, and whether it is running. Colour is spent there (info / warning / danger / success edge) and nowhere else on the page. Below it the case timeline says what happened in order.
- **Portals: what exactly the external user sees, and until when.** The scope preview is now a per-person, record-by-record verdict (seen on which page, hidden by which gate, expired, or on no page) with the date each record stops being reachable, plus what stays hidden.
- **Assets: the asset, its right and where it is used.** The detail header leads with the licence state; the Rights tab lists the uses that lapse with the licence; replacement is validated (licence, file, approval, shape, format) before anything moves.
