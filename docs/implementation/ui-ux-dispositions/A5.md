## Headquarters

- **ARL-HQ-001 Executive Home.** Worked: personality (spectrum bar, orbit, routing line, stat markers), real Finance and approval figures. Deficient: the state line used the old 44px clamp and ran four lines; Waiting-on-you rows were boxed panels with long wrapped summaries. Compared with: Finance invoice detail for density.
