# B5 · Integrations + IT + Forms — dispositions

**Signatures.** CONNECT: the provider, its consent scopes and whether the connection is real (state comes only from the capability register; "connected" never appears without a verified backend grant). / IT: the incident, its severity clock (elapsed time, no invented SLA) and the evidence that gates resolution. / FORMS: the field, its validation and where responses go (this workspace only; no mail provider).

**Counts (125 overlay rows, shared ids repeat per screen):** Enhanced 3, Rebuilt 1, Refined 65, Restructured 20, Verified 36. Screenshots under scratchpad `shots/B5/`.


## Page reviews (priority screens)

- **Connector authorisation (`/connect/connect/<id>`).** Deficient: hero card restated title, a second state pill, no consent summary. Changed: RecordHeader (provider, register state, consent none, scopes 0 of N) plus a one-line honesty band. Why: connected state only from the register. New functionality: none. Tested: integrations-native-experience, w2f CONNECT.
- **Connection detail (`/connect/connections/<id>`).** Deficient: duplicate identity card. Changed: RecordHeader with register and setup state; Overview card retitled Account and authorisation. Tested: same specs.
- **Incident detail (`/it/incidents/<id>`).** Deficient: title card repeated the header, no clock. Changed: RecordHeader with severity, stage, elapsed clock, owner, service, origin; Details card; critical severity and repair approval permission-bound. Tested: manual sweep; no IT spec exists.
- **Form builder (`/forms/forms/<id>`).** Deficient: ~330px of title, tiles and toolbar above the canvas. Changed: one bar with form picker, state, actions and inline counts; field editor as a sectioned inspector. Tested: forms-library-experience.
- **Submissions.** Changed: RecordHeader (form, version, responses), compact search and counts, Submission drawer rebuilt. Tested: forms-library-experience.
- **All other screens.** Headline filler removed from Connect, Forms overview bands (aria-labels kept); Properties replaced by KeyValueList across the three apps.
