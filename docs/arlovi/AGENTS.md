# Arlovi Engineering Agents — Required Rules

This repository contains the handoff for the complete Arlovi frontend. First read `01_CURSOR_PROMPTS/ARLOVI_MASTER_CURSOR_GROK_PROMPT.md` and `00_READ_ME/START_HERE.md`, then source specs in `07_ORIGINAL_SPECIFICATIONS/`. If this folder is installed under `docs/arlovi/`, adapt these paths accordingly.

Implement the whole native-suite frontend: 35 application domains, 316 registered screens, 1323 tab instances, 956 overlays, 1328 primary actions, 20 cross-app workflows. No backend in this phase. All buttons meaningful, data persisted in browser where feasible, no fake external transactions, no prototype/demo labels in product UI. Six workstreams are defined in `04_WORKSTREAMS`; every feature receives independent UX and functional review. No MVP scope reductions. The user has authorized routine executive product decisions by the orchestrator; document significant tradeoffs rather than asking them to micromanage engineering.
