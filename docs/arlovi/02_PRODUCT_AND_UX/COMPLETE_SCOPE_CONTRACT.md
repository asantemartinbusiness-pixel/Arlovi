# Arlovi — Complete Frontend Scope Contract

## Mandate
The full registered company headquarters and native suite are in-scope. The mandate is not an MVP. Required: 35 app domains, 316 distinct screens, 1323 tab instances, 956 context overlays, 1328 named actions, 20 cross-application workflows and 21 shared UI surfaces. There is no "build-first" subset to declare finished in lieu of the complete target. Project execution may use parallel branches, internal sequencing and dependencies, but acceptance requires every listed domain and screen.

## User-facing quality
A polished working product without demo/prototype/MVP/coming-soon banners. All controls must operate. App-specific UX, no identical generic dashboard everywhere. Brand configurable; initial working name Arlovi and electric cobalt + papaya + aqua palette. Full responsive experience, accessible, dark mode, comfortable/compact density, animated with restraint. Human and AI users visibly distinct.

## Frontend-only boundary
All browser-feasible actions should actually work in-browser, with IndexedDB persistence and meaningful import/export. No API server, cloud database, real login, secret credential storage, external side effects, hosted AI inference or genuine multiuser sync unless later supplied through supported backend interfaces. UI may fully model every step, but must honestly stop/mark unconnected actions at the provider boundary. Document the limitation in developer files; product UI can use precise language such as "Connect account" or "Service not connected" instead of demo labels.

## Completion evidence
No screen complete without route + meaningful distinct content + real tabs + working actions + real overlays + states + persistence where relevant + keyboard/mobile/accessibility + tested navigation and independent review. No action marked verified merely because a local function returned. Cross-app data identities and authorization flows must be coherent.

## Naming and rights
Arlovi is a working brand, not cleared. Existing Arlovi commercial use and the exact .com was flagged in research; assistant naming may change. Use central brand config and rename-safe paths. Verify license compliance of every third-party creative/editor dependency and bundled asset.
